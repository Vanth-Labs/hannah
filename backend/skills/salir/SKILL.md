name: salir

terminal: exit
phrases: ["salí de la sesión", "sali de la sesion", "desconectate", "desconéctate", "cerrá la sesión", "cerra la sesion", "salir de ssh", "salí de ssh", "exit"]

Use when the user wants to LEAVE / close the current interactive terminal session — for
example, to disconnect from an SSH session. It sends `exit` to the terminal. Takes no input.
