# hannah-frontend
## Setup / assets not included

```bash
npm install --legacy-peer-deps   # obligatorio: vite 5 vs @vitejs/plugin-basic-ssl 2.3 (peer vite >=6)
npm run dev                      # predev copia los assets del VAD; https, port 5173
npm run build
npm run lint
```

Necesita el **backend en :3001** (Vite proxea `/api` y `/ws` hacia allí). Con `HANNAH_HTTP=1`
sirve HTTP en vez de HTTPS — es el modo que usa el launcher `./hannah` para el overlay.

Excluded from the repo (add locally):
- `public/avatar.glb` — kept (the VRM, the only avatar rendered today).
- `public/smplx_avatar.glb` — debug-only, excluded AND no longer rendered (the SMPL-X debug
  component was removed; regenerate with `hannah-backend/sidecar/motion/build_avatar.py` if
  you ever need it back).
- `public/vad/` — generated by `predev` (`scripts/copy-vad-assets.mjs`), gitignored.
- `public/animations/*.fbx` — raw Mixamo clips (Adobe license). Download from Mixamo
  (FBX Binary, Without Skin, 30fps) into `public/animations/`, then bake:
  `node scripts/bake_mixamo.mjs` → regenerates `public/animations/baked/*.json` (committed).
